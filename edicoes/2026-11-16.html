VibePrevisBench: Evaluating Agentic Coding for 4D Scene Generation in Blender

Por Yuzhe Chen, Muxi Diao, Lele Yang, Wenbin Xu e mais 18 · Kling-Keye

Controllable real-world video generation models can condition on a rendered graybox proxy video, which fixes layout, motion and camera. Coding agents can build such videos by reconstructing a 4D scene in Blender, yet no benchmark checks both these videos and the long, multi-shot scenes behind them. We introduce VibePrevisBench, a benchmark for 4D scene reconstruction: an agent turns a brief into an executable 4D scene and renders its proxy video. Its 242 tasks span four input kinds, including scripts, photos, continuations, and reference videos. Each delivery is scored along two evaluation dimensions. Rule-based Scene Check re-runs the code and compares the exported 4D scene with hidden ground truth facts in nine dimensions. VLM-based Screen Check asks a VLM judge whether the facts that pass can be recognized in the proxy video. We analyze the evaluation results and trajectories of 11 frontier coding agents and identify three key observations. First, multimodal understanding separates the agents, especially in understanding space and camera motion. Second, all agents seem to already master basic camera work and staging, and fail at challenging requests. Third, agents inspect their own renders but fail to correct their errors. Agents thus need better visual understanding of space and camera, explicit checks for challenging requests, and item-by-item verification of renders against the brief.

Interpreting Coding Agents Through Their Behavioral Trajectories

Por Ibragim Badertdinov e Alexander Golubev · Nebius

Standard coding-agent benchmarks primarily evaluate binary task success, treating execution as a black box and obscuring the behaviors that produce those outcomes. We analyze a large corpus of 143,209 execution trajectories from 125 agent configurations spanning 117 unique models. We find that agents with similar solve rates can nevertheless differ substantially in how they explore, modify and verify code.

HerAgent: A Block-Level Checkpointing Harness for Coding-Agent Environment Setup

Por Xiang Li, Siyu Lu, Federica Sarro e mais 2

Modern coding agents rely on establishing executable software environments before they can perform software engineering tasks such as testing, debugging, and patch validation. We present HerAgent (Harness EnviRonment Setup Agent), a block-level harness for coding-agent environment setup. Evaluated against six prior agents on four environment-setup datasets, HerAgent improves setup success in every comparison, achieving the largest gains on Installamatic-Bench (52.0% to 85.0%) and SetupBench (46.3% to 70.4%).

We present PrivacyPR, a dataset of 4,131 merged GitHub pull requests (PRs) from 1,469 repositories, created between June 2018 and January 2024. Super-Analysis for Aggressive yet Scalable Compiler Optimization

Por Amirali Ebrahimzadeh e Amir Shaikhha

Meta Build Systems as Logic Programs

Por Alex Reinking

Meta build systems such as CMake, Meson and Bazel derive command graphs from project descriptions, user choices and machine facts. We introduce buildlog, a meta build system whose stratified logical core isolates build derivation from impure environmental probes. The results show that confining impurity to fact discovery yields a small, uniform and explainable configuration semantics.
