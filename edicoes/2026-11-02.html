Cognitive Inclusivity in AI Coding Assistants: Evidence from GitHub Copilot

Por Grace Kerr, Aarushi Parasrampuria, Faith Culas e Kelly Blincoe

AI coding assistants are commonly used for daily software development tasks. While prior research has examined their impact on productivity and code quality, less is understood about how these tools support diverse ways of thinking. Evidence from non-AI software engineering tools suggests that mismatches between tool design and users' cognitive styles can introduce inclusivity barriers, but it remains unclear whether similar issues arise in AI coding assistants. We investigate how developers with different cognitive styles experience and interact with these tools and whether they exhibit cognitive inclusivity challenges. We conducted a controlled laboratory study with 20 student participants using GitHub Copilot to complete code generation, debugging, and refactoring tasks. Using think-aloud protocols, semi-structured interviews, and inductive thematic analysis, we identify patterns in user interaction. We then apply the GenderMag framework to examine how these patterns differ across cognitive styles. We identify five inclusivity issues concerning how Copilot explains suggestions, supports validation, facilitates learning, exposes its features, and influences the problem-solving process. Our findings suggest that common interaction paradigms in AI coding assistants can privilege certain cognitive styles while introducing additional cognitive effort for others. We derive design implications for more inclusive AI coding assistants.

RepGen: Reproducing Deep Learning Bugs through Context-Aware Code Generation and Verification

Por Mehil B Shah, Mohammad Masudur Rahman e Foutse Khomh

Reproducing deep learning (DL) bugs is challenging because failures can involve source code, models, data, dependencies, and execution environments. We present RepGen, an open-source tool for reproducing DL bugs through context-aware code generation and iterative verification. A controlled study with 27 developers showed a 23.35% improvement in reproduction success and a 56.8% reduction in reproduction time.

ROSTrans: Empirically Benchmarking LLMs for ROS1-to-ROS2 Migration

Por Yichen Zhao, Minghao Shao, Zhuoyan Yu e mais 4

Although large language models have shown strong capabilities in domain-specific code generation, their performance in robotics software development, especially for the Robot Operating System (ROS), remains largely unexplored. We present ROSTrans, a benchmark for evaluating LLMs on ROS1-to-ROS2 code migration, a representative and practically important setting for ROS code generation. Evaluating six frontier LLMs over five stochastic generations per task, we find pass@1 below 10.9%, and that 56.5% of all samples build successfully and then fail at runtime,and 32.0% fail runtime assertions on the migrated interfaces, a class of error no compile-only oracle can detect.

On 75 BugsInPy bugs, we retried each of 181 failed attempts of gpt-5.4-mini under five conditions, with a predeclared analysis whose deviations we report. An Empirical Study of Gas Optimization Practices in Solidity Smart Contracts

Por Francesco Salzano, Paolo Martino, Simone Scalabrino e mais 2

In the Ethereum ecosystem, smart contract execution is governed by a gas model where every computational operation incurs a direct economic cost. This paper presents an empirical study investigating gas optimization practices in open-source Solidity repositories created on GitHub between 2018 and 2025. Our findings reveal that optimization efforts span multiple levels of abstraction, from low-level arithmetic refinements and bytecode-size reductions to broader architectural changes such as logic internalization and external call reduction.

Iris on Indirection Theory: Lightweight Higher-order Ghost State

Por Darius Foo, Viet-Anh Nguyen e Wei-Ngan Chin

Today, semantic models of languages with concurrency and higher-order state are constructed using step-indexed predicates over resources and higher-order ghost state. We conduct two case studies to show that the base logic is expressive and faithful to Iris: a biorthogonal logical relation for higher-order state, and an Iris-style program logic with invariants and user-definable ghost state, complete enough to verify concurrent and higher-order programs.
