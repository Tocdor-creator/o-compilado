"Shall We Approve?" Consequence-Aware Approval for Autonomous Coding Agents

Por Weiheng Wu, Junkai Chen, Zhensu Sun, Jieke Shi e mais 2 · Singapore Management University

Caper pre-executes shell commands in isolated sandboxes to evaluate real-world effects before approval, reducing harmful outcomes compared to text-based approvers.

Coding agents increasingly rely on automated approvers to decide whether a proposed shell command may run. Existing approvers, from rule-based checkers to guardrail models and deployed permission classifiers, base their decisions on the text of the request and command. Yet a command's behavior depends on the code it invokes and the state of the workspace, and systems that observe file changes leave the assessment to the agent or a human after execution. We present Caper, a consequence-aware approval mechanism that pre-executes each command in a snapshotted sandbox, provides an independent approver with a bounded report of its observed effects, commits allowed commands, and rolls back blocked ones with a reason the agent can act on. Compared with six existing systems, Caper achieves the lowest harmful-outcome rate on SABER (6.7% versus at least 14.8%) and YoloFS-Ext, a benchmark we build in which harmful behavior is hidden inside invoked tools (7.8% versus at least 35.3%), while blocking 1.0% of the safe twins of the dangerous tasks in YoloFS-Ext.

Switch-SWE: Do Coding Agents Hold Focus When Switching Between Unfinished Tasks?

Por Shuochen Chang, Qianli Ma, Yibo Miao e mais 7 · Shanghai Jiao Tong University

A benchmark for resuming interrupted software tasks reveals performance drops from interleaved work, and a context-management module improves recovery.

Software development sessions often involve several unfinished tasks rather than one issue carried through to completion. We introduce \ourmethod, a benchmark for focus-task resumption in sessions that interleave unfinished tasks drawn from the same source repository, with a persistent checkout for each task. On OpenCode, the module improves focus-task completion under same-repository task switching by 5.5 to 15.5 percentage points across the evaluated models.

Warpline: Binary-Level Tracing and Unified Evidence for Agentic GPU Kernel Optimization

Por Junyu Yin, Vinod Grover e Keren Zhou

LLM agents are becoming GPU kernel engineers, but they still tune kernels without seeing where the time goes. We present Warpline, which gives agents this view automatically while leaving the kernel essentially unchanged. On NVIDIA B200, across 35 kernels in Triton, CuTe DSL, and CUDA C++, Warpline adds a median overhead of 1.2% and leaves a median 99.9% of executed instructions unchanged, whereas existing tracers have median overheads of 1.6% to 13.2% and leave only 4.6% to 32.7% unchanged.

te-comp: A Complete MLIR Compiler Generating Self-Contained C Inference Engines for MCUs

Por Van Chan Ngo

Deploying deep learning on microcontrollers (MCUs) requires fitting both the model weights and runtime activations within tens to hundreds of kilobytes of SRAM and Flash. In this paper, we present te-comp, the first complete MLIR-based compiler that takes a standard model in .tflite or .safetensors format and emits all C source files needed for deployment: the inference engine (kernels, weight arrays, memory layout) and the RTOS integration layer with zero runtime dependencies. On 10 MCUNet CNN benchmarks, te-comp outperforms MCUNet TinyEngine by using 38% less SRAM (up to 5.9$\times$) and 15% less Flash, while generating complete C code rather than linking a pre-written kernel library.
